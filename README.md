# 💄 Mua Hapsari - Professional Portfolio & Services

Website portofolio dan profil profesional yang dirancang untuk menampilkan layanan jasa tata rias (Makeup Artist) dengan estetika visual yang elegan dan memikat.

## 🚀 Live Demo
🔗 [Akses Website Mua Hapsari di Sini](https://muahapsari.vercel.app/)

---

## ✨ Fitur Utama
- **Galeri Portofolio:** Menampilkan hasil karya makeup terbaik dengan layout visual yang elegan.
- **Informasi Layanan & Harga:** Rincian paket jasa yang ditawarkan secara transparan.
- **Call to Action (CTA):** Tombol interaktif untuk memudahkan klien melakukan pemesanan atau *booking*.

---

## 🛠️ Tech Stack
- React.js / Vite
- Tailwind CSS
- Git & GitHub
- Vercel
