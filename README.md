# Hapsari Beauty Studio

# PROJECT

Buatkan sebuah Single Page Landing Page premium untuk jasa Make Up Artist bernama **MUA Hapsari**.

Landing page harus memiliki tampilan yang elegan, mewah, feminin, modern, bersih, dan profesional. Pengunjung cukup melakukan scrolling dari atas ke bawah tanpa berpindah halaman.

Tujuan utama website adalah membuat calon pelanggan tertarik dan langsung melakukan booking melalui WhatsApp.
